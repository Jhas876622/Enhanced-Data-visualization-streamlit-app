# 📊 Advanced Data Visualizer

A powerful and interactive **Streamlit-based Data Visualization Web App** designed for analysts, students, and data science learners. This application allows users to **upload datasets, explore sample data, generate synthetic data, perform statistical analysis, visualize relationships, and build custom plots** — all within an intuitive and visually appealing dashboard.

---

## 🚀 Features

* 📤 Upload your own CSV dataset
* 📚 Load built‑in sample datasets (Iris, Tips, Stock Prices)
* 🎲 Generate random synthetic datasets
* 📋 Dataset overview (rows, columns, types)
* 🔎 Data preview & missing value analysis
* 📈 Multiple charting options with **Plotly & Seaborn**
* 📊 Statistical summary and plots
* 🔗 Relationship & correlation analysis
* 🎨 Multiple color themes
* 🧩 Advanced visualizations including heatmaps, pair plots, and 3D plots
* 🎯 Fully customizable filtering and charting

## 📥 Installation & Setup

### 1️⃣ Clone Repository

```bash
git clone https://github.com/jhas876622/advanced-data-visualizer.git
cd advanced-data-visualizer
```

### 2️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 3️⃣ Run the App

```bash
streamlit run app.py
```
